# راصد

**تصميم / عبدالله المخلافي 2026**

راصد آلة حاسبة عربية ذكية تعمل كتطبيق ويب قابل للتثبيت PWA، وتدعم حفظ النتائج داخل الجلسة بصيغة R1 وR2 وR3 وإعادة استخدامها في عمليات لاحقة.

## التشغيل محليًا

شغّل المجلد عبر خادم HTTP، مثل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080` في Chrome أو Edge. عند دعم المتصفح للتثبيت يمكن تثبيت **راصد** كتطبيق مستقل أو إنشاء اختصار له.

## الوظائف الرئيسية

- إدخال من أزرار الشاشة والكيبورد ولوحة Numpad.
- نتائج متتابعة قابلة لإعادة الاستخدام: R1 وR2 وR3 وما بعدها.
- تحديد عدة نتائج أو تحديد الكل.
- جمع وطرح وضرب وقسمة ومتوسط للنتائج المحددة.
- إظهار إجمالي النتائج المحددة باستمرار أسفل التحديد.
- تحويل ناتج المجموعة إلى نتيجة R جديدة.
- تثبيت النتائج المهمة للوصول السريع أثناء الجلسة.
- سجل رأسي بتمرير وأسهم أعلى وأسفل.
- نسخ قيمة الناتج فقط ولصق رقم من الحافظة.
- تراجع وإعادة، واختيار المنازل العشرية، وأصوات مختلفة مع زر كتم.
- واجهة واسعة بثلاث لوحات مع خيار إخفاء التفاصيل.
- تبدأ جلسة جديدة فارغة عند إعادة تشغيل التطبيق.
- تخزين ملفات التطبيق للعمل دون اتصال عبر Service Worker، دون حفظ نتائج الجلسة.

## Windows

الواجهة مبنية بـ HTML وCSS وJavaScript معيارية دون اعتماد على خادم. يمكن تغليف الواجهة نفسها لاحقًا بواسطة Tauri لإنتاج مثبت Windows دون إعادة كتابة منطق الحاسبة.
